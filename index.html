共享内存生命游戏 SharedArrayBuffer × 真实 Worker

当前环境不支持 SharedArrayBuffer 跨源隔离。

本应用需要 Cross-Origin-Opener-Policy: same-origin 与 Cross-Origin-Embedder-Policy: require-corp 两个响应头（window.crossOriginIsolated === true）。

不会偷偷退化成单线程：请用 npm run dev 或 npm run preview 启动（已配置隔离头），或在你自己的静态服务器上补齐这两个头后再打开。
